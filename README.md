# Spirit Discovery Experience

A single-screen, responsive discovery journey with a changing celestial landscape. Visitors answer nine short questions; progress, route position, and sky colors shift as they go.

## Run locally

Open `index.html` in a browser. No install or build step is needed.

## Demo notes

The questionnaire uses the supplied discovery flow with conversational copy, back navigation, optional skips, and a restartable results view. Answers stay in page memory and are not saved.

Results include up to two sample products with a small sample plan for each. They are illustrative demo records, not verified or bookable services; availability, price, duration, and destination URLs are not supplied. The therapy example is withheld until professional credentials and eligibility are verified. Spiritual preferences are respected, including a non-spiritual path.

The visual direction uses a celestial palette and moon/circle motifs. Komet and PF Marlet Display were named in the supplied brand guide but are not bundled here, so available font fallbacks are used.
